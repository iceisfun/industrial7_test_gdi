## Done (verified)
- Recorder probes for 8 families + `hello` + `ui_metrics_ss6`: font_metrics, char_widths, face_substitution, ui_metrics, control_heights,
  glyph_bitmaps, dpi_scaling, font_inventory (probes/, REC v1 in docs/PROBE_FORMAT.md, tools/rec.py).
- Real Windows 10 22H2 (19045.2965) recordings in `data/win10/<probe>/` (101 files, all validate with `tools/rec.py validate`): DPI 96 full for every
  family, DPI sweeps 96..192 for ui_metrics / control_heights / dpi_scaling, control_heights v6 manifest variant, ui_metrics cold144 reference.
  Each family has a README (what, rows, boots, determinism). Provenance logs: `data/win10/_runs/`.
- Determinism: two fresh boots identical for 6 families; the documented exceptions are `GetSystemMetrics` idx 93 and `SystemParametersInfoForDpi` at
  72 dpi (undefined cells) and the sweep-vs-cold-boot DPI state (see data/win10/ui_metrics/README.md: use cold144 as the 144 reference).
- Local oracle: `tools/win10_run_local.sh` runs a throw-away qcow2 overlay of a Win10 base image in QEMU with the payload on a CD and
  results over COM1; `tools/vm_run.sh` drives it (docs/VM_RUN.md).
- Conformance tests (`tests/<area>/`, 15 areas, 238 tests): the nine older areas (core_smoke, char_widths, control_heights, dpi_scaling,
  face_substitution, font_inventory, font_metrics, glyph_bitmaps, ui_metrics) and six new areas, each with an `EVIDENCE.md` (source of every
  expectation, observe-only items flagged): glyph_indices_and_ranges, font_resources, kerning_placement, outline_and_abc,
  text_output_extents, font_enum_order. The whole set was run on the Windows 10 22H2 19045.2965 guest with `tools/vm_test.sh` in separate
  boots: every area PASS with 0 skips, logs identical between boots. Two older-area test bugs
  found by that run were fixed: `SystemParametersInfoForDpi(.., dpi 0)` returns TRUE on Windows 10 (the tests asserted failure, based on a
  decompilation), and char_widths printed unwritten `GetTextExtentExPointW` partial extents.
- `tools/vm_test.sh` + `tools/vm_test_split.py`: run any number of test areas on the guest in one boot (docs/VM_RUN.md section 7).
- `COVERAGE.md` (generated by `tools/gen_coverage_md.py` from `tools/coverage.py`, `tools/uncovered_justified.txt`,
  `tools/coverage_observe_only.txt`): static, name-based; 1443 distinct gdi32/gdi32full names, 146 called by a test, 6 of those observe-only.
  `HANDOFF.md` describes how to continue.
- One probe bug fixed on real Windows: control_heights sent TTM_GETBUBBLESIZE under comctl32 5.82 (access violation); now only under v6.
